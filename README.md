# NOIR FRAME STUDIOS

A responsive cinematic photography website built with HTML, CSS and JavaScript.

## Included
- Responsive one-page layout
- Portfolio/gallery placeholders
- Services
- Photography packages
- Testimonials
- Booking form
- WhatsApp buttons
- Mobile navigation
- Scroll reveal animations

## Run
Open `index.html` in a browser.

## Customize
1. Replace the placeholder blocks with your photography images.
2. Change the WhatsApp number in the two `wa.me` links.
3. Update prices and package details.
4. Replace social links.
5. Connect the booking form to a backend/email service when you want live submissions.

## GitHub Pages
Upload `index.html` and `README.md` to a GitHub repository, then enable GitHub Pages from Settings > Pages.
